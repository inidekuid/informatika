Prinsip FIFO — First In First Out (Yang masuk pertama, keluar pertama)

REAR (masuk) ➡

📖 Cara Kerja Queue

Enqueue Menambah data di bagian belakang (Rear)
Dequeue Mengambil data dari bagian depan (Front)

Contoh nyata:
• Antrian di kasir minimarket
• Antrian printer (dokumen yang dikirim lebih dulu dicetak lebih dulu)
• Antrian tiket bioskop / bank

Perbedaan dengan Stack:
• Stack = LIFO (Last In First Out) → seperti tumpukan piring
• Queue = FIFO (First In First Out) → seperti antrian orang

💻 Kode yang sedang dijalankan

class Antrian:
def __init__(self):
self.data = [] # Menyimpan antrian
 
def enqueue(self, orang):
self.data.append(orang) # Masuk di BELAKANG
print(f"{orang} masuk antrian")
 
def dequeue(self):
if len(self.data) > 0:
orang = self.data.pop(0) # Keluar dari DEPAN
print(f"{orang} selesai dilayani")
return orang
else:
print("Antrian kosong!")
 
def lihat_depan(self):
if self.data:
return self.data[0]
return None

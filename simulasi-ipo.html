Mengapa Materi Ini Penting?
🔴 Skenario Nyata

Anda sedang mengetik tugas di laptop sambil menyalakan musik di Spotify, chatting di WhatsApp, dan video YouTube loading di background. Kenapa semua bisa jalan bersamaan? Bagaimana komputer memutuskan tugas mana yang dikerjakan duluan? Apa artinya "CPU 80%"?

Komputer modern tidak "tahu" bagaimana bekerja. Semua instruksi diterjemahkan menjadi 1 dan 0, diproses di CPU dengan ritme tertentu, disimpan di memori, dan dikeluarkan ke layar. Sistem operasi adalah maestro yang mengatur semuanya itu agar terasa seamless.

Tujuan Anda: Dari pengguna pasif yang hanya melihat icon → menjadi pemikir kritis yang memahami "black box" komputer.

💭 Renungkan

Bayangkan laptop Anda adalah sebuah kantor. Kepala kantor adalah CPU, lemari arsip adalah memori, dan pekerjaan masuk melalui pintu depan (input). Setiap pekerjaan diproses, disimpan, dan hasilnya dikirim keluar. Siapa yang mengatur alur kerja agar tidak chaos? Itu adalah sistem operasi!

Arsitektur Von Neumann

Hampir setiap komputer modern menggunakan desain yang sama, yang dinamai John von Neumann pada tahun 1945. Arsitektur ini memiliki lima komponen utama:

📌 Komponen Kunci
  • Input: Perangkat yang membawa data ke komputer (keyboard, mouse, sensor, microphone)
  • CPU: "Otak" komputer. ALU melakukan perhitungan, CU mengatur instruksi
  • Memori (RAM): Penyimpanan cepat tempat CPU membaca dan menulis data saat sedang diproses
  • Output: Perangkat yang menampilkan hasil (layar, printer, speaker)
  • Storage: Penyimpanan permanen (hard disk, SSD) untuk data jangka panjang
💭 Pertanyaan Refleksi

Ketika Anda mengetik di keyboard dan teks muncul di layar, alir mana yang terjadi? Input → CPU → RAM → Output, atau urutan yang berbeda? Coba jelaskan dengan diagram sendiri!

Model Input-Proses-Output (I-P-O)

Setiap operasi komputer mengikuti pola yang sama: data masuk → diproses → hasil keluar. Mari simulasikan!

🎮 Simulasi I-P-O Interaktif
💡 Contoh Nyata

Mengetik kata "hello":
INPUT: Keyboard mengirim sinyal untuk setiap tombol yang ditekan
PROSES: CPU mengubah sinyal keyboard menjadi kode ASCII (72, 101, 108, 108, 111) dan menyimpannya di memori
OUTPUT: GPU menampilkan karakter di layar

💭 Latihan

Amatilah simulasi di atas. Di mana data tersimpan saat PROSES sedang berlangsung? Kapan data dihapus dari memori?

Sistem Operasi dan Arsitektur Berlapis

Sistem Operasi (OS) adalah perantara antara pengguna dan hardware. OS mengelola memori, proses, file, dan antarmuka. Arsitektur OS sering digambarkan sebagai model bawang berlapis:

🔍 Fungsi-Fungsi Sistem Operasi
  • Manajemen Memori: Mengalokasikan dan membebaskan RAM untuk program yang sedang berjalan
  • Manajemen Proses: Mengatur giliran program mana yang mendapat CPU (CPU scheduling, multitasking)
  • Antarmuka dengan Hardware: Menerjemahkan perintah program ke instruksi hardware
  • Antarmuka Pengguna: GUI (ikon, mouse) atau CLI (terminal, perintah teks)
  • Manajemen File: Menyimpan dan mengorganisir data di storage
Jenis-Jenis Sistem Operasi
🖥️ Desktop OS

Windows, macOS, Linux. Digunakan untuk komputer pribadi dan workstation. Fokus pada performa dan kemudahan penggunaan.

📱 Mobile OS

Android, iOS. Dioptimalkan untuk layar kecil, baterai terbatas, dan sensor (GPS, accelerometer).

🖲️ Embedded OS

RTOS (Real-Time OS). Tertanam dalam mesin: mobil, oven, smart TV. Respon cepat, resource terbatas.

⚙️ Server OS

Linux server, Windows Server. Dijalankan 24/7, mengelola jutaan koneksi, fokus pada stabilitas.

💡 Contoh: Multitasking

Anda mengetik + Spotify playing + YouTube loading. Ketiga proses ini TIDAK benar-benar berjalan bersamaan di CPU 1-core. OS membagi waktu CPU sangat cepat (context switching) sehingga terasa simultaneous. Inilah yang disebut multitasking!

💭 Renungkan

Buka Task Manager (Windows) atau Activity Monitor (Mac). Lihat berapa banyak proses yang sedang berjalan. Apakah Anda benar-benar membuka semuanya? Apa yang OS lakukan dengan proses yang tidak Anda gunakan?

🤖 Aktivitas 1: Simulasi Mesin Sederhana (SAP)

Simulasikan mesin komputasional paling sederhana. Anda adalah CPU.

Instruksi:

Instruksi yang tersedia: LOAD n (baca nilai), ADD n (tambah), SUB n (kurang), STORE addr (simpan ke alamat), PRINT (tampilkan), HALT (berhenti)

📊 Aktivitas 2: Gambarkan Alur I-P-O

Pilih satu aktivitas harian dan gambarkan alur I-P-O-nya:

  • ✅ Mengirim pesan WhatsApp
  • ✅ Menonton video TikTok
  • ✅ Membuka file Word dan mengeditnya
  • ✅ Bermain game di smartphone

Tulis: Apa INPUT-nya? Apa yang CPU/OS lakukan? Apa OUTPUT-nya?

🔍 Aktivitas 3: Pengamatan Langsung Sistem Operasi

Windows:

  • Buka Task Manager (Ctrl+Shift+Esc)
  • Catat CPU %, Memory %, Disk % yang sedang digunakan
  • Buka program berat (game, video editor) → lihat perubahan

Mac:

  • Buka Activity Monitor (Spotlight → Activity Monitor)
  • Lihat tab CPU → catat proses yang paling berat
  • Berapa % CPU mereka gunakan?

Linux:

  • Buka terminal → top
  • Lihat kolom %CPU dan %MEM

Catatan: Apa yang membuat komputer lambat? Biasanya CPU 100% atau Memory penuh!

Ringkasan & Peta Konsep

📝 Poin-Poin Kunci

  • Von Neumann architecture terdiri dari INPUT → CPU → MEMORI ↔ OUTPUT
  • Model I-P-O menggambarkan setiap operasi: Data in → Process → Result out
  • Sistem Operasi adalah maestro yang mengatur semua komponen
  • OS melakukan context switching untuk membuat multitasking terasa seamless
  • RAM digunakan untuk penyimpanan sementara, Storage untuk penyimpanan permanen
  • Komputer lambat biasanya karena CPU penuh atau memori penuh
